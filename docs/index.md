# Salesforce Permission Export

A Chrome extension built for Salesforce architects and administrators to export
Profile and Permission Set permissions to Excel at enterprise scale.

## What it does

- Exports field permissions, object CRUD, Apex class access, VF page access,
  and system permissions to Excel
- Compare any two profiles or permission sets side-by-side
- Batch export your entire org — all profiles and permission sets — as ZIP files
- Works on all Salesforce org types: Production, Sandbox, Scratch, Dev Edition
- All processing happens locally in your browser — nothing is sent to any server
